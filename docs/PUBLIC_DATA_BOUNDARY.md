# Public Data Boundary

This research repository is intended to publish reproducible, non-sensitive computational artifacts.

Publicly released:
- executable notebooks;
- source code;
- research method documentation;
- aggregate result definitions;
- dashboard source and live prototype URL.

Not publicly released:
- raw institutional SIUTER/SIAKAD logs;
- respondent-level expert validation data;
- identifying information;
- credentials or tokens;
- private deployment infrastructure details.
