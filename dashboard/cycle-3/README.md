# ER-CyRIS Cycle 3 Dashboard

## Live Dashboard

https://ercyris-siklus3-v3.fathoni-ee4.workers.dev/

The dashboard is a research prototype for presenting detection metrics, SHAP explainability, operational triage, NIST-oriented risk mapping, robustness, and near-real-time benchmark results generated by Cycle 3.

The dashboard is not positioned as a commercial SIEM product. The `M7 → M3` relationship remains a proposed design-level feedback path unless separately demonstrated by executed experiments.
