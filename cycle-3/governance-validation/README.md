# Governance Expert Validation

This directory documents the governance validation instrument used in Cycle 3.

The public repository includes the instrument definition (`src/governance_validation_round1.gs`) but does not publish raw expert responses, respondent-identifying information, or embedded alert answer keys.

The validation focuses on governance constructs including evidence traceability, sensemaking adequacy, decision-authority alignment, contestability and escalation, learning from overrides, institutional enactment, and accountable reliance.

The instrument is distinct from technical alert validation and dashboard usability assessment.
